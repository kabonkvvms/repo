Music Bridge Setup Guide

Back to Music Bridge

Music Bridge plays Spotify or Amazon Music in Microsoft Edge on your Windows PC and streams the audio over Wi-Fi to jailbroken devices running iOS 6. Keep the PC and Edge running while you listen.

Already set up on Windows? Skip to the iPhone install.

1. Set up Windows

Keep the complete Windows Music Bridge folder together, including Start Music Bridge.cmd and link-code.txt.

  1. Install 64-bit Python 3.13. Enable Add Python to PATH if the installer offers it. Python for Windows
  2. Install Microsoft Edge if it’s missing. Microsoft Edge
  3. Download and extract a Windows build of FFmpeg. Search Windows for Edit environment variables for your account, open your user Path, and add the folder that contains ffmpeg.exe. Open a new PowerShell window after saving. FFmpeg downloads
  4. Install VB-CABLE. Extract the download, run the installer that matches your Windows architecture as administrator, and choose Install Driver. Restart if prompted. Confirm that CABLE Input (VB-Audio Virtual Cable) appears in Windows Sound settings. VB-CABLE download
  5. Install the Python packages and check FFmpeg from a new PowerShell window. 
    py -3.13 -m pip install PyAudioWPatch winrt-Windows.Media.Control playwright
ffmpeg -version
    If you installed Python 3.13 and Windows doesn’t recognize py, use python in its place and omit -3.13.

2. Start the bridge

  1. Double-click Start Music Bridge.cmd. Choose 1 for Amazon Music or 2 for Spotify.
  2. Sign in directly in the dedicated Edge window. Play a song so Edge appears in Windows Settings → System → Sound → Volume mixer.
  3. Set Edge’s output to CABLE Input or Music Bridge, whichever matches the launcher's Capturing line. Keep your normal speakers or headphones as the Windows default.
  4. If Windows Firewall prompts you, allow Python on Private networks. Connect the iPhone and PC to the same local network.
  5. Copy the full LAN address printed after Open on iOS Safari, including port 8096 and the code after it. Leave the launcher and Edge open.

To switch services, press Ctrl+C in the launcher or close the dedicated Edge window. Reopen the launcher and choose the other service.

3. Install the iPhone app

  1. On the jailbroken iPhone running iOS 6, open Cydia → Manage → Sources → Edit → Add.
  2. Add https://kabonkvvms.github.io/repo/. If the source is already listed, refresh it.
  3. Install or upgrade Music Bridge. Cydia installs the Retro Icons package and WinterBoard when needed. Follow any prompt to respring.
  4. Open the app and enter the full playback address from the Windows launcher under Settings. Tap Done on the keyboard.

4. Listen and control playback

  • Tap Home → Listen on iPhone. Play controls Edge and can resume the current song or replay a recent one.
  • Use Search for songs or Library for playlists. Tap a playlist to view its tracks and use Play/Pause.
  • Tap the song-info bar to open Now Playing. Drag the progress bar to seek when the Windows player supports it.
  • In Settings → Theme, Auto uses green for Spotify and blue for Amazon Music. Choose a Home Screen icon in WinterBoard → Select Themes and respring to apply it and its matching label.

Troubleshooting

  • The app can’t connect. Match the full playback address from the launcher, including its code. Confirm both devices are on the same local network.
  • Track info updates but the iPhone is silent. Check that Listen on iPhone is active and Edge’s output matches the launcher’s Capturing line.
  • The bridge can’t find the virtual output. Check that VB-CABLE is installed and that any requested restart has finished.
  • The app shows the wrong service or port 8096 is busy. Close older bridge and dedicated Edge windows, then start one launcher.
  • Search or Library won’t load. Restart the Windows launcher, check the sign-in in the dedicated Edge window, and refresh the Library on the iPhone.
  • The audio stutters. Stop listening, select Settings → Playback mode → Standard, and start listening again. Standard buffers longer.
